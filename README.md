# Для начала...
** 1. Установите на ваш ПК "Radmin VPN"**
-
** 1.1 Если вы хотите подключиться к оригинальным серверам ( Lunar ), то нажмите на "Подключиться к сети"**
-
** 1.1.1 Вводите такие данный в поля: " Логин: ClydeChatLTS ; Пароль: ClydeClydeClyde2 ", запускаете клиент, и вы подключили наши сервера.**
-
** 1.2 Если вы хотите свой сервер создать для чата, нажмите на "Создать сеть"**
-
** 1.2.1 Вводите логин и пароль для вашего сервера ( с какого ПК вы сделали сеть, на том должен быть Server Клиент ) **
-
** 1.2.2 Подключаетесь к серверу по 1.1 и частично 1.1.1**
-
** 1.2.3 Заходите на другом устройстве в Клиент и вводите команду "Edit IP"**
-
** 1.2.4 Вводите в поле IP адрес вашего сервера(ПК) который подключен к RadminVPN ( в консоли отображается этот IP ) **
-
** 1.2.5 Позже вы попатаете в меню, создаёте чат и всё!**
